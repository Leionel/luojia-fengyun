### 关系和行为初始规则

开局人物或组织关系由内容配置给出，默认信任 20、目标一致 0、纽带 0，无争端。玩家与摄影社初谈时双方信任 20；与音乐社 15；与旧书社 30。每个方向更新独立。履约常用 `trust +12, bond +6`，如期提供人手 `trust +8, bond +5`，明确已签违约 `trust −20` 并加一个有证据的争端。带限定的修复方案通常补偿后 `trust +8` 且转 `remediating`，再次小合同成功后再 `+12` 并解除对应争端。无协议的礼貌拒绝最多产生方向性一致度调整及机会记录，不算失信。章末按新目标重新计算一致度，纽带靠共同经历递增。数据范围见架构，规则统一截断。

角色每窗口比较「继续任务、提前交付、寻求合作、学习休息、提出修复或离开」。可行性先核验：时间、能源和占用。规划评分的初值为 `3×目标匹配 + 2×到期紧迫 + 2×互惠机会 + 角色偏好 + 合法收益 - 2×过载 - 2×失败风险`，特征以 0–3 归一。权限和本人意愿是约束；正式签约、超授权或任务转给不愿接的人不会因得分高而绕过。实时 AI 可因目标、未了冲突和机会换行动或对象。若连续两个已发出并且未处理的过载预警、仍没有被同意的替班/降载，则给本人休整或离开候选；出发前本窗口安排移交。紧急休假也可以直接生效，由项目走受托人与暂停规则。

成长证据由已完成的练习里程碑产生。相同练习重复交同一份材料不晋级。例：阿柠须有两个不同的有效排班练习、监督记录和复盘，才解锁双入口排班；阿南从两次实际触达不同受众取得同周分渠道能力。新手选择导师必须本人同意，安排双方工时，并可因未履行承诺更换导师。

## 3. 三条可跨章重放的因果链

### L1 · 你拒绝了摄影社，此后它选了别人

1. **W02–W05，根 `PHOTO_DECLINED`。** 玩家拒绝平等联摆或拒绝对方更高署名。记录原报价、拒绝理由、双方、开学活动 ID。礼貌拒绝只移动对玩家的目标一致度 −6，强抢同一场次才新增公开争端。
2. **W06–W08，`PHOTO_MUSIC_JOINED`。** 摄影社候选转向音乐社。若音乐社有工时、需要宣传且报价达保留条件，两家角色各自接受后签约。签约会占走一套相机与一个黄金档，舞台挂两面旗。若双方都忙，摄影转向独展，年鉴引用实际发生的替代。
3. **W09–W11，`PROMOTION_ROLE_REVIEW`。** 根事件仍有证据、阿南署名目标未达且连续两个窗口处于低目标一致度，发起路线争论。玩家可缩宣传保学业、补偿给真正主办权、或维持独立让阿南另找项目。转会是角色后续自主行为，与旧争端可以并存。
4. **W14–W16，`PHOTO_SPRING_APPEAL`。** 摄影社人手缺少 ≥2h 且需春季展示，向可行伙伴独立发邀请。无争端、信任≥30 时提出对等互惠；存在已违约争端时要求先交 ¥40 押金或只接受小任务；信任低于 0 且争端未修复时优先找技术社。玩家可补偿、提三方分工或拒绝。五月牌桌只引用已签协议与已履约证据。
5. **W18–W24，`MAIN_STAGE_CONTROL` 与投票。** 两次真实履约或已经确认的联盟章程提高主办提案资格。失约仍可补救，但补偿后仍需一次履约。换届时阿南对曾给机会且真正交付的人更支持，票理由可回到 W09 事实。

根事实与 W14 是否对玩家可见分开。去重键 `PHOTO_SPRING_APPEAL|PHOTO_DECLINED.id|counterparty`。摄影临时自己解决了缺口则取消调度并记录原因，不能强行借危机构造剧情。测试用同种子比较公平接受、礼貌拒绝、抢位并二次拒绝三轨，检查独立签约、可用相机、真实待办、不同报价与选票；刷新 W14 可恢复旧交易版本。

### L2 · 人很多，入口却只有一条

1. **W03 或 W15，`AUDIENCE_SPIKE`。** 某活动有来源证据的宣传触达提升，报名 ≥ 接待容量的 120%，产生一个候补观察实例。以项目 ID 定范围，排队量为报名减可入场。六天等期点内同项目只出现一次提醒，后续只有新受众/新容量下再次跨线才生成实例。
2. **同窗口，`QUEUE_RESPONSE`。** 放开报名并付 ¥60 增设 12 人容量，需要 4h 人工；付 ¥25 加开实名时段且取消 6 个超额预约，需要 2h；与旧书社借雨棚和志愿者可加 8 人容量，但织入署名和归还义务。每条对项目、报名、人员预约和钱包实际结算。未有足够现金/人手时仍可缩场或说明等待；过期用公开缓报方案，禁止承诺无上限入场。
3. **W08 或 W16，`WAITLIST_DISPUTE`。** 违背给定席位且未补救的人形成真实退订与返款记录。压力过大又有账款迟延时，小予提出暂停新增宣传；已提前公开候补、实际接待质量达阈值时用户可保留口碑并进入同行小场机制。
4. **W10、W17 和 W24。** 秋季被缩场的成员若获得导师与实际项目，可以在五月从主舞台转展廊，或通过补岗维持规模。年鉴展示气氛和带来的代价，明年若承诺有剩余必须续交，而非用结局等级抹掉。

边界：0 容量表示关闭，显示「暂不可入场」，不除以零；高峰度可重复出现但实例和收益不重复；终期退款要返实际付款。测试锁定报名 72、容量 50、可用旧书社排班三轨。分别验接待、时段移交和是否出现支持者流失。快速挑战的候补阈值独立。

### L3 · 十月借出去的一张桌子

1. **W04–W05，`BOOKCLUB_ASSISTED`。** 旧书社招募短缺、玩家拥有未预约折叠桌和可交付的 2h，玩家可借设备+工时，或按 ¥30 短租，亦可婉拒。发起后预约 1 张桌到约定归还日，免费帮助先写义务，真实完成才记 `bond +6, trust +12`；付费短租正常结款但互惠标记类型不同。
2. **W10–W14，`BOOKCLUB_EXPANDED`。** 杜舒自主推进交换角。两次小活动都完成后获得两班志愿者能力。若旧书社没发展出人手，五月可提供雨棚或联系人，不能生成它没有的物资。
3. **W16/W20，`BOOKCLUB_RETURN_OFFER`。** 玩家失去露天场地或缺 4h 人手，旧书社确有空闲且此前帮助已完成。信任≥40 且无日期冲突可以调一班志愿者，附带共同署名；交换角撞期时提前开半小时或改用设备，报价有真实成本。玩家也可拒绝借力，向技术社争取后备。
4. **W21/W24，`MUTUAL_HELP_CLOSED`。** 实际支援、归还与交接完成会生成联盟评价和下一年联办资格；拿了雨棚但未归还则出现押金/争端，不记为完成。历史可从五月舞台的两面旗沿因果跳回十月桌椅预约。

根事实 ID＋原箱子拥有者作实例键，多个项目同天缺工以预约冲突裁决。测试相同五月雨况，比较十月有/无帮助及旧书社正常/取消成长，检查人手不能凭空出现。另测提前承诺撞期时已有项目优先、对方真实反价。
